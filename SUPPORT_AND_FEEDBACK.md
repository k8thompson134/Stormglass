# Support & Feedback Guide

## Getting Help

### For General Questions

**Email:** support@stormglass.app

We'll respond within 24 hours (often faster) with answers to:
- How do I use feature X?
- Why isn't my location showing up?
- Can you add support for [condition]?
- How do I delete my data?

---

### For Accessibility Issues

If you have difficulty using Stormglass due to:
- Screen reader compatibility
- Keyboard navigation
- Color contrast or visibility
- Mobile responsiveness
- Motor or motor-control issues

**Email:** accessibility@stormglass.app with:
1. What device/browser you're using
2. What assistive technology (if any)
3. What's not working
4. A screenshot if helpful

**Priority:** We treat accessibility bugs as critical and will prioritize fixes.

---

### For Privacy/Security Concerns

**Found a potential security vulnerability?**  
Email: security@stormglass.app

- **Do not:** Post vulnerability details publicly
- **Do:** Include exact steps to reproduce
- **We will:** Respond within 48 hours, work with you on a fix, and credit you (if desired)

**Privacy question about your data?**  
See [PRIVACY_POLICY.md](PRIVACY_POLICY.md) or email: support@stormglass.app

---

### For Bug Reports

**Where:** GitHub Issues (preferred for technical bugs)  
**Or:** Email: support@stormglass.app

**Include:**
1. **What happened:** "When I clicked X, instead of Y, Z happened"
2. **Steps to reproduce:** Numbered steps so we can recreate it
3. **Expected behavior:** What should have happened
4. **Device/browser:** Chrome on iPhone 14, Firefox on Mac, etc.
5. **Screenshot:** If visual, a screenshot helps enormously

**Example bug report:**
```
Title: Symptom log button doesn't respond on mobile

Steps:
1. Open Stormglass on iPhone 12 (Safari)
2. Tap "Log symptom" button in header
3. Modal doesn't appear; button doesn't highlight

Expected: Modal should open

Device: iPhone 12, iOS 17.2, Safari
```

## Feature Requests & Ideas

### What We're Open To
- Tracking additional conditions (with research backing)
- New environmental factors (pollen spikes, dust storms, air pressure drops)
- Export formats (CSV, PDF, JSON for personal health records)
- Integration with habit-tracking apps
- Accessibility improvements
- Language translations

### What We're Probably Not Building
- Medical diagnosis features ("you have migraines")
- Medication recommendations
- Wearable integrations (Fitbit, Apple Watch)
- Prescription tracking (use a dedicated pharmacy app instead)
- Social features (public symptom sharing, leaderboards)

### How to Suggest Features

**Email:** feedback@stormglass.app

**Include:**
1. **What you want:** Clear one-sentence description
2. **Why you want it:** What problem does it solve?
3. **Who benefits:** Just you? People with POTS? Everyone?
4. **How we could build it:** If you have ideas

**Example request:**
```
Title: Export symptom logs as PDF report

Why: I want to share my patterns with my rheumatologist in 
a clean format she can file with my medical records.

Who benefits: Anyone with healthcare providers who want 
written documentation of their pattern research.

Suggestion: Export last 30/60/90 days with charts and 
data summary.
```

## Community Feedback

### Help Us Improve for Your Community

We're building Stormglass for chronic illness communities. Your feedback shapes what we build next.

**Types of feedback we actively seek:**

- **Are the conditions accurate?** Do the tracked factors match your real experience?
- **What's missing?** What conditions should we support?

## What Happens With Your Feedback

1. **We read it** — Every message goes to the team
2. **We consider it** — We look for patterns (one request = idea, ten requests = trend)
3. **We respond** — For bugs and support, we reply directly; for features, we acknowledge receipt
4. **We iterate** — Feedback shapes our roadmap and priorities
5. **We credit you** — If your feedback leads to a feature, we'll mention you (unless you prefer anonymity)

## Known Limitations & Workarounds

### "My location isn't updating"
- Check that you entered the city name correctly in Settings
- Try entering a larger city nearby
- Clear browser cache and reload

### "Geomagnetic data seems off"
- We use NOAA's Kp index; sometimes data is delayed by a few hours
- Refresh the page to pull latest data

### "I want to delete just one symptom log"
- Click the X button on the log entry; it will delete immediately (no undo)
- If you delete by mistake, email support@stormglass.app within 48 hours; we can potentially recover it

### "I can't export my data yet"
- Feature coming soon! Email feedback@stormglass.app if this is urgent
- Workaround: Take screenshots or use browser DevTools to inspect localStorage
